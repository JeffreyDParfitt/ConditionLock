Device/platform behavior to support:

Same-platform upgrade:
- If user upgrades from one iPhone to another iPhone and uses the same Apple ID, they should be able to restore purchase.
- If user uses iPhone and iPad with the same Apple ID, they should be able to restore purchase.
- If user upgrades from one Android phone to another Android phone and uses the same Google account, they should be able to restore purchase.

Cross-platform switch:
- If user switches from iOS to Android, purchase entitlement does not transfer automatically.
- If user switches from Android to iOS, purchase entitlement does not transfer automatically.
- User can still export packet archives from the old device and import those archives on the new device.
- User may need to purchase again on the new platform.

No-backend requirement:
Do not create a user account system.
Do not create server-side entitlement syncing.
Do not create cross-platform purchase syncing.
Do not create cloud storage.
Do not upload packets/photos/hashes/archives.

Because ProofPacket has no backend:
- Purchase restore should eventually rely on Apple App Store / Google Play / RevenueCat platform restore.
- Cross-platform entitlement transfer is not supported.
- Data portability is handled through Full Packet Archive export/import.
